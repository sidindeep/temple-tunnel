# Temple Tunnel 0.14.1

Исправлено предупреждение «Не удалось проверить системную защиту» при запуске.
В 0.14.0 запрос перечисления WFP-фильтров не указывал слой. В повышенном
процессе Windows возвращала `FWP_E_LAYER_NOT_FOUND` (2150760452), а интерфейс
ошибочно предлагал проверить права администратора.

Теперь фильтры перечисляются отдельно для ALE_AUTH_CONNECT_V4 и V6.
При очистке сначала собираются идентификаторы; удаляются только фильтры
с provider и sublayer Temple Tunnel. Ошибки доступа и ошибки конфигурации
WFP различаются в сообщениях интерфейса.

Проверка выполнена в повышенной PowerShell: `status` вернул `off`, все три
режима `validate` успешно создали правила внутри отменяемой транзакции.
Блокирующие фильтры не включались. Это проверка Windows API и конфигурации,
а не проверка реальных утечек при аварии. Также проходят 157 автоматических тестов.
