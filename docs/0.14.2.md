# Temple Tunnel 0.14.2

Исправлен выбор исключений приложений через «Диспетчер задач» при включённом
Kill switch. При добавлении процесса клиент проверяет PID и имя, получает полный
путь EXE (в том числе для службы Windows) и передаёт его в правила маршрутизации
и WFP. Сохранённые исключения только по имени обновляются при запуске, если
соответствующий процесс работает и Windows позволяет определить его путь.

Случай Kerio проверен на уровне получения пути службы и конфигурации правил;
запуск Kerio после Temple Tunnel на установленной версии требует проверки.
Блокировка Avito по IP оставалась и при выключенном Temple Tunnel, поэтому
маршрутизация сайта в этой версии не менялась.
